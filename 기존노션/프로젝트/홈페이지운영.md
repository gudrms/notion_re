홈페이지 운영 및 유지보수

- 기간 : 2023.06 ~ 2025.05
- 팀 구성 : 2명
- 역할 : 팀원 (풀스택 개발자)
- 기술 스택
    - Backend : Java 8 (Spring Boot 2.3.4), MyBatis, Oracle DB, Spring Security
    - Frontend : jQuery, JavaScript, JSP, Apache Tiles
    - 도구 : Maven, Jenkins, SVN, Git
- 주요 업무
    - 문진표 시스템 운영 : RESTful API 기반 의료진-환자 간 문진표 처리
    - 검진 예약 관리 : 검진 코드별 예약 관리 및 층별 안내 시스템
    - 성능 최적화 : MyBatis 쿼리 최적화, HikariCP 커넥션 풀 구성
    - CI/CD 구축 : Jenkins 자동화 배포, 환경별 설정 분리
    - APM을 통한 트러블 슈팅 및 장애 대응
