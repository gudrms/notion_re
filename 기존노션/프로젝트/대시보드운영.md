1. 대시보드 운영(EIS)
   📅 기간 : 2023.06 ~ 2024.02 (8개월)
   👥 팀 구성 : 2명
   🎯 역할 : 팀원 (풀스택 개발자)
   🛠 기술 스택
- Java, Spring Boot, Oracle Database, MyBatis, jQuery, JavaScript, JSP, Chart.js, Gradle

📋 주요 업무

- 데이터 시각화 : Chart.js 기반 매출 트렌드, 고객만족도 지표 차트 구현
- 실시간 대시보드 : Ajax 비동기 데이터 로딩 및 차트 업데이트
- 데이터 적재 시스템 : KMIHomepageBatch 스케줄러를 통한 매출 데이터 자동 수집

### 📖 내용

- 회사의 매출과 고객만족도 등을 차트와 그래를 통해 전시하는 페이지
- 요구사항에 맞게 디자인 및 차트 수정
- chart.js를 이용

### 🙋‍♂️ 역할
