   🎯 역할 : 풀스택 개발자 (프론트엔드 & 백엔드 담당)
   🛠 기술 스택
- Backend : Node.js, Express.js, Prisma ORM, PostgreSQL
- Frontend : React, Next.js, TypeScript, Tailwind CSS, Ant Design
- 인증/보안 : Next-Auth, Keycloak SSO, JWT, Crypto-js
- DevOps : Docker, GitLab CI/CD, Yarn Package Manager
- 기타 : i18next(다국어), QR코드, GSAP, Swiper, Axios

🎯 주요 성과

- 기존 Java/JSP 레거시 시스템을 Node.js 기반 MSA로 전환
- Docker 컨테이너화 및 GitLab CI/CD 파이프라인 구축
- React 기반 SPA로 전환하여 페이지 로딩 속도 개선
- TypeScript 도입으로 런타임 에러 감소

- 디지털 문진표 시스템 : React + TypeScript 기반 동적 폼 생성
- 전자동의서 관리 플랫폼 : PDF 생성, 전자서명, QR코드 연동
- 모바일 식권 시스템 : QR코드 스캔 및 실시간 검증 시스템
- 통합 회원 관리 : Keycloak 기반 SSO 및 권한 관리
- 관리자 대시보드 : 실시간 모니터링 및 각종 게시판 관리
- 태블릿 문진표: 병원 내 문진표 작성
